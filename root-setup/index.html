Root key setup

Set up a root key that is born on this device and never travels. The keypair is created here, in your browser, and stored on this device only. You send the operator the public half — that part is safe over any channel — and they bind it to your root handle. The private half leaves this device only inside an encrypted backup that you hold.

Before you start

  • Public is safe, private is sacred. Send the operator the public block from this page — never the backup file unencrypted, never a screenshot of anything but the public block.
  • The backup is not optional. Phones get lost. The recovery kit you download below is the only way back in, so this page will not call your key ready until you have saved it.
  • Generating a key does not make it a root key by itself — the operator still binds the new key id to your handle before claims under it verify.

The kid names this key — one per device. The suggestion uses this device's place in your handle; keep it unless the operator told you otherwise.

Restore from a backup

New device? Restore your root key from the recovery kit you downloaded. The file is decrypted here, on this device — the passphrase and the key never leave it.
