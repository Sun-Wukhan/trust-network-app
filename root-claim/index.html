Root key claim

Prove — through the app, on the record — that you hold a root private key. The server issues a one-time challenge, your browser signs it with your key, and the server checks the signature against the published root key and records a receipt.

The guarantee

Your private key never leaves this device. A key file is read in this tab's memory only — never uploaded, never stored. A key generated on this device (root key setup) stays in this device's storage and is used here, in place. Either way only a signature is sent — a signature proves you hold the key without revealing it, and it is worthless for anything except this one challenge.

Claiming changes nothing about your key or your identity. You can claim again at any time; each claim is a fresh proof, and the receipts below are the public history.

With a key file: No root key is stored on this device for that handle — set one up on the root key setup page, or use a file below.
